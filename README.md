## 📘 Overview

Welcome to the **Global Agro-Ecological Zoning (GAEZ) version 5** GitHub repository.  
This repository provides access to resources and documentation describing the **GAEZ v5 methodology**, developed by the **Food and Agriculture Organization of the United Nations (FAO)** and the **International Institute for Applied Systems Analysis (IIASA)**.

GAEZ offers a scientific framework for quantifying land productivity and evaluating agricultural potentials under various biophysical and management conditions.
