# 💻 GAEZ v5 Data Access Notebooks

This directory contains **Jupyter Notebooks for programmatic access to and download of GAEZ v5 datasets**.

The notebooks provide practical examples of how to query the **GAEZ v5 API**, select datasets based on user-defined parameters, and download the corresponding data for use in external analyses and workflows.


## 📓 Available Notebooks

### GAEZ v5 Module 2 Data Downloader

The **Module 2 Data Downloader** provides an interactive workflow for selecting and downloading GAEZ v5 datasets related to **Agro-climatic Potential Yield**.

👉 [Open the Module 2 Data Downloader](./gaez_res02_downloader_selection_notebook.ipynb)


### GAEZ v5 Module 5 Data Downloader

The **Module 5 Data Downloader** provides an interactive workflow for selecting and downloading GAEZ v5 datasets related to **Suitability and Agro-ecological Attainable Yield**.

👉 [Open the Module 5 Data Downloader](./gaez_res05_downloader_selection_notebook.ipynb)


## 🚀 Getting Started

The notebooks can be downloaded and run in a local **Jupyter Notebook** or **JupyterLab** environment.

To use a notebook:

1. Open the relevant notebook above.
2. Download the `.ipynb` file from GitHub.
3. Open the notebook in Jupyter Notebook or JupyterLab.
4. Run the cells sequentially and follow the instructions provided in the notebook.
5. Select the required GAEZ v5 datasets and parameters.
6. Download the selected data for further analysis.
