# 🌍 GAEZ v5 Platform Resources

The **GAEZ v5 Platform** provides open access to geographic and tabular data from the Global Agro-Ecological Zoning (GAEZ) version 5 assessment. It enables users to **explore, query, visualize, analyze, and download** GAEZ v5 spatial datasets through an interactive web-based environment.
The platform provides access to GAEZ v5 results organized into six main thematic areas:

- **Land and Water Resources**
- **Agro-Climatic Resources**
- **Agro-Climatic Potential Yield**
- **Suitability and Attainable Yield**
- **Actual Yields and Production**
- **Yield and Production Gaps**

Users can search and explore datasets, visualize spatial patterns, perform time-series analysis, compare datasets, define areas of interest, conduct geospatial analyses, and access tabular crop summary information. The platform also provides dataset metadata and options for downloading GAEZ v5 data for further analysis.


👉 [Access the GAEZ v5 Platform](https://data.apps.fao.org/gaez/?lang=en)

## 📝 How to Cite GAEZ v5 Data

When using data obtained from the GAEZ v5 Platform, please cite the source as follows:

> **Source:** FAO (Food and Agriculture Organization of the United Nations) & IIASA (International Institute for Applied Systems Analysis). 2025. *Global Agro-Ecological Zoning version 5*. [Accessed on DD Month YYYY]. [https://data.apps.fao.org/gaez/](https://data.apps.fao.org/gaez/). Licence: CC BY 4.0.

Please replace **[Accessed on DD Month YYYY]** with the date on which the data were accessed.

## 📘 GAEZ v5 Platform User Guide

The **GAEZ v5 Platform User Guide** provides detailed information to help users understand and work with the datasets available through the platform.

The guide covers:

- the organization of GAEZ v5 datasets into themes, sub-themes, and variables;
- how to explore and access data through the platform;
- how to download raster datasets from cloud storage;
- GAEZ v5 variables and codes;
- GAEZ v5 naming conventions.

Users are encouraged to consult the guide and the GAEZ v5 methodology documentation when interpreting and using GAEZ v5 data.

👉 [GAEZ v5 Platform User Guide](https://github.com/un-fao/gaezv5/wiki/21.-GAEZ-v5-Platform-User-Guide)

## 💻 Data Access Notebooks

For users who need to access GAEZ v5 data outside the interactive platform, this repository also provides **Jupyter Notebooks for data access and download through the API**.

The notebooks allow users to select GAEZ v5 datasets based on relevant parameters and retrieve the corresponding data through the API for use in GIS, modelling, and other analytical workflows.

Currently available examples cover:

- **Agro-Climatic Potential Yield**
- **Suitability and Agro-ecological Attainable Yield**
